# salidas

Aquí se generará el documento markdown único de entrada para la herramienta corporativa de
especificaciones (uno por lote de procesos analizados).

Esta carpeta se sincroniza con el remoto: al iniciar una sesión se hace `pull` para traer las
salidas ya generadas por otros compañeros, y tras la validación final del usuario se hace `push`
junto con la memoria (ver sección "Sincronización con Git" del README principal).
