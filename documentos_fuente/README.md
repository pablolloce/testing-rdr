# documentos_fuente

Coloca aquí los documentos técnicos que el agente debe analizar (Word, PDF convertido a texto,
markdown, etc.). El agente los leerá íntegros antes de generar el documento de salida.

Esta carpeta **nunca se sube al repositorio remoto** (ver `.gitignore`). El agente no debe
incluir su contenido en ningún `git add`/`commit`/`push`, aunque el usuario lo autorice para
`salidas/` o `memoria/`.
